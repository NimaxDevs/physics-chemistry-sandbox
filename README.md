A 2D physics &amp; chemistry sandbox (or simulator) written in **Python** which is based on **Newtonian mechanics, optics, fluid mechanics, thermodynamics, basic chemistry principles and more.** Built as a part of Hack Club's and NASA Stardance Challenge, this project allows you to **combine real-time physics and chemistry equations** to your own liking by creating your own experiences.

## Main Features
A bunch of simulations that well, are under this line:

⚛️**Physics Simulations**
- **Newtonian Mechanics:** Customizable simulations of forces such as projectiles, pendulums, springs, planet orbits and gravity
- **Fluid Mechanics (W.I.P):** Fluid simulation in which physical properties extracted from Navier-Stokes equations (viscosity, pressure, density) can be changed
- **Optics:** Refraction of light calculated through Snell-Descartes Law
- **Thermodynamics:** Simulates entropy increasing or decreasing under the influence of heat or cold in a "virtual" with properties such viscosity calculated by Sutherland's Law, diffusion coefficients for the particles calculated with Stokes-Einstein equations and real-life constants for realism and accuracy

⚗️**Chemistry simulations**
- **Study of Matter:** First 16 elements of the Periodic Table simulated according to Bohr's Atomic Representation Model
- **Molecular Dynamics:** Solution Maker to create chemical solutions by selecting a solvent and solute in a certain quantity, Molecular Lab to display some organic molecules, Reaction Lab (W.I.P) to simulate chemical reactions when different reactants are put together, Combustion Simulation (W.I.P) so as to simulate the colorful flame produced by the combustion of some chemical elements as well as the Smoke Simulation (W.I.P) to simulate the smoke produced by the combustion and Atom Collision Simulation (W.I.P) to simulate atoms from the Periodic Table colliding into each other

🚀**Launcher**
- **Complete Local Launcher:** No web links or anything like that; the launcher is a `.exe` file that can be executed in **Windows** computers.
- **Preview and Configuration Tabs:** Tabs to see the simulations before selecting them with thumbnails and descriptions as well as configuration tabs to change and select the values of the physical & chemical properties to simulate with sliders, buttons, checkboxes, switches and text entries
- **Simulation-Launcher Interface:** Interface between the Launcher and the Simulations which can be launched from it
- **`.json` File Management:** Files created to store the values selected or changed in the simulation configuration tabs with simulation IDs as well as the Launcher Settings
- **Launcher Settings:** Options to cap the FPS and activate or deactivate V-Sync
- **Custom Theme:** Rime, a theme made by `a13xe` and `webbrain-one` for a colorful touch
- **Light Mode:** As the name says, a mode to recreate the look from the older Operating System (Windows 8, Vista)
- **Segoe UI font:** A omplement to the older Operating System (Windows 8, Vista) look included in the Launcher and the simulations
- **UI Sounds:** Dynamic UI sounds when clicking and hovering the buttons of the launcher
- **Credits Tab:** A credits tab to give credits to the authors of the assets used
- **Custom Icon:** A custom icon made for the Launcher and Simulation windows

# 🛠️ Installation and requirements
Just downolad the `.exe` file from the Releases tab of the GitHub repository and run it on your computer!
Platforms supported: Windows only
